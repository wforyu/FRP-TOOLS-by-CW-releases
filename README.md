# FRP Tool by Cw — Releases

Repositori ini **hanya** berisi aset rilis (installer) untuk **FRP Tool by Cw**.
Source code utama bersifat **privat**.

Aplikasi ini memeriksa update otomatis melalui GitHub Releases API pada repositori ini
(endpoint: `repos/wforyu/FRP-TOOLS-by-CW-releases/releases/latest`).

## Unduh

Ambil file `FRPTool-Setup-<versi>.exe` terbaru dari tab **Releases**.

## Catatan

- Installer **belum ditandatangani** secara digital; Windows SmartScreen dapat menampilkan
  peringatan "Unknown publisher". Pilih *More info* -> *Run anyway*.
- Aplikasi membutuhkan hak **administrator** (menulis folder data `backup\`, `da\`,
  `programmer\`, `fdl\`, `bin\` di samping executable).
- Versi terbaru = tag dengan angka terbesar. Versi aplikasi terpasang ditampilkan di
  status bar aplikasi (klik **"Cek update"** untuk memeriksa manual).
